# india-states.geojson

36 states and union territories, geometry simplified (tolerance 0.02 degrees) from the DataMeet state boundary shapefile (States/Admin2).
Source: https://github.com/datameet/maps (DataMeet India community), licensed CC BY 4.0 unless stated otherwise in that repository.
Attribution required: show "India state boundaries: DataMeet (CC BY 4.0)" in the map footer and README.

Not verified against the current Survey of India official map. Before any official submission or public deployment, compare the outlines (especially Jammu & Kashmir, Ladakh and Arunachal Pradesh) with the official Survey of India map and replace this file if they differ. Property `name` holds the state name.
